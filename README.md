# Savestate releases

Download installers for [Savestate](https://github.com/TylerFleischman/savestate-app)
from the [Releases](https://github.com/TylerFleischman/savestate-releases/releases) page.

- **macOS**: the `.dmg` for your chip (`arm64` for Apple silicon, `x64` for Intel).
- **Windows**: `Savestate-Setup-<version>.exe`. The installer is unsigned for now, so
  SmartScreen will warn once; choose "More info" then "Run anyway".

Installed copies check this repo for updates on launch. This repo holds no source; it
exists only because the app's update feed must be public while the source is not.
